# Learning to Hiring Platform

A comprehensive platform that bridges the gap between technical learning and hiring, featuring coding practice, AI-powered interview coaching, resume building, social networking, and analytics.

## 🚀 Features

- **Coding Practice** - Solve problems across DSA, OOPs, HLD, LLD, and SQL
- **AI Interview Coach** - Practice behavioral, technical, and leadership interviews
- **Resume Builder** - Create ATS-optimized resumes
- **Analytics Dashboard** - Track your progress and performance
- **Community** - Connect with other learners
- **Social Posts** - Share technical videos and insights

## 🛠️ Tech Stack

### Frontend
- React 18.3.1

- React Router DOM

- CSS (Separate files per component)

### Backend (Coming Soon)

## 📦 Installation

### Frontend
```bash
cd frontend
npm install
npm run dev
```

The application will be available at `http://localhost:3000`
